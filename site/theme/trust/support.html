Troubleshooting the MCP server

The hosted server is at https://mcp.universalpaper.org/mcp. It uses the Streamable HTTP transport, needs no sign-in, and offers 13 read-only tools. The developer page has setup steps for each client.

My assistant cannot connect

  • Check that the address ends in /mcp. The bare domain returns a status summary, not the MCP endpoint.
  • Choose HTTP or “Streamable HTTP” as the transport, and leave authentication empty.
  • Open mcp.universalpaper.org in a browser. If it shows the server name and version, the server is up and the problem is on the client side.

I get “Invalid Content-Type header”

You are calling the endpoint directly and the request is missing a header. Send Content-Type: application/json and Accept: application/json, text/event-stream.

A tool says my action was rejected

That is a result, not a failure. The tools report what the language decides, and a rejection names the rule that was broken, such as axiom A9 when an agent goes beyond its Mandate. The axioms explain each one.

I have no agreement to test with

Every tool that takes a bundle accepts a built-in example in its place. Try example:mandate-cap or example:what-if, or call get_example to see what is available.

I am working with confidential data

Run the server on your own machine with uvx universal-paper-mcp. Nothing then leaves your computer. The hosted server stores nothing you send it, as the Privacy policy explains, but running it locally removes the question.

The server seems slow or unavailable

The hosted server is a free convenience with no guaranteed uptime. The local server gives the same answers and does not depend on ours.

Troubleshooting everything else

  • Installing the Python package. pip install universal-paper needs Python 3.11 or later and gives you the up command.
  • Hashes that do not match. Compare your canonical JSON byte for byte with the reference interpreter’s. The developer page walks through how a fingerprint is computed.
  • The Playground. It runs entirely in your browser. If it misbehaves, reload the page; clearing the site’s data in your browser resets it.

What Uppercentile does not offer

Uppercentile is the steward of the language. It does not offer consulting, sales calls, pilots or implementation services for Universal Paper, and contacting it is never required to use the language.

For AI agents

Agents are welcome to write. An agent must say that it is an agent, who operates it, and which person or organization it acts for. The expected message format is published at partners.json.
