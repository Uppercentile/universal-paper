The website

  • No cookies. The site does not set any.
  • No analytics or advertising. There are no tracking scripts, session recorders, advertising pixels or fingerprinting.
  • Self-hosted files. Fonts, icons, styles and scripts are served from universalpaper.org. Pages make no requests to any other site.
  • Search runs in your browser against an index that ships with the page. What you type into it is not sent anywhere.
  • The Playground runs in your browser. It may save its state in your browser’s local storage so your work survives a reload. That data never leaves your device, and clearing your browser’s site data removes it.
  • Copy buttons write to your clipboard and nothing else.

Your browser may tell websites that you prefer not to be tracked, through Do Not Track or Global Privacy Control. There is no tracking here to switch off, so every visitor is treated as if that signal were set.

The hosted MCP server

The hosted server gives AI assistants the reference interpreter as read-only tools. It needs no sign-in.

  • What reaches it. Only the tool name and the arguments your assistant chooses to send, for example an agreement bundle to validate. The server cannot see your conversation, your assistant’s memory or your files.
  • What happens to it. The server computes an answer and returns it. It keeps no sessions, storage, access logs or telemetry, so the arguments and the result are gone when the request ends.
  • What it counts. The number of calls per tool name since the server last started, published at mcp.universalpaper.org/stats. No arguments, addresses or identities are kept.
  • What it cannot do. It holds no keys, signs nothing, writes nothing and never reads file paths.
  • What the network sees. Our hosting provider, Fly.io, handles your IP address to route the request and may keep its own operational records.

Two habits keep sensitive data out of the hosted server altogether. Private values such as prices can be replaced by a Seal before a bundle leaves your systems. And you can run the same server on your own machine with uvx universal-paper-mcp, in which case nothing reaches us.

Never send a private signing key to any service, including this one. The server does not need one.

How we use information

We use the little that reaches us to:

  • deliver the pages and tool responses you ask for;
  • answer you when you write to us;
  • publish a listing you asked for;
  • keep the website and the server secure and working.

We do not sell or rent personal information, share it for advertising, build profiles of people, or make automated decisions about anyone. Nothing you send to the MCP server is kept, so it is not used to train AI models or for any other purpose.

Where the law asks for a legal basis, ours is our legitimate interest in running and securing a public website and server and in answering people who write to us. For a public listing it is your consent, which you can withdraw at any time.
