Universal Paper is an open language that writes a purchasing agreement once as signed, fingerprinted data. This guide is for people using it through Claude. It gets you connected, then walks through six things to try, each with a prompt you can copy and the result it returned.

Quickstart

Three steps to a first answer.

  1. Add the connector

    If Universal Paper appears in Claude’s Connectors Directory, add it from there. Otherwise add it by its address:

    1. Open the Connectors directory, select Add, then Add custom connector. Or use this prefilled link.
    2. Enter the name Universal Paper and this address, then select Continue:
      https://mcp.universalpaper.org/mcp
    3. The server needs no sign-in. Keep the settings Claude detected and select Add.

    On Team and Enterprise plans an Owner adds it under Organization settings > Connectors. Members then find it in their own connectors.

    Add the hosted server:

    claude mcp add --transport http universal-paper https://mcp.universalpaper.org/mcp

    Or run it on your own machine, so nothing leaves it:

    claude mcp add universal-paper -- uvx universal-paper-mcp

    Any client that speaks the Model Context Protocol can connect.

    SettingValue

  2. Turn it on in a chat

    In a new chat, select + in the message box, find Universal Paper under Connectors, and turn its toggle on. You choose this in each conversation.

  3. Send a first prompt

    You ask

    Walk me through a Universal Paper agreement using the conventional example. Who are the parties, what does it say, and is it valid?

    Claude asks before it uses a tool. Select Allow once, or Always allow to skip the question next time. Every tool is read-only, so allowing one changes nothing on any system.

    You should see Claude load the example, check it and read it back: a master agreement between Hypothetical Health Purchasing Alliance (the aggregator) and Example Medical Supply Co. (the supplier), with eight clauses, and valid. If you see that, you are connected. If not, go to Troubleshooting.

How it works

Claude does the writing and the reading. The connector does the computing.

01You ask

In plain words. No syntax to learn.

02Claude picks a tool

It builds the input from your words or from an agreement you give it.

03Universal Paper computes

The reference interpreter applies the rules of the language and returns the answer with the rule and the reason.

That split matters. When Claude reads a contract on its own, you get an interpretation. Here the answer comes from a rule engine, and the same input gives every party the same answer. Claude’s wording will vary from chat to chat. The verdicts, amounts, dates and fingerprints will not.

Five words appear throughout this guide:

Bundle
One file holding agreements and their history. Every tool that takes a bundle also accepts a built-in example, such as example:what-if.
Term
A standard clause with typed values, such as an admin fee or a price tier. There are 16.
Fingerprint
A 64-character hash of an agreement. If two parties hold the same fingerprint, they hold the same agreement.
Event
A signed step in an agreement’s history: propose, accept or attest.
Mandate
Signed limits on what an AI agent may do for a party.

Draft a deal

Describe the terms in plain words. Claude builds the agreement from the standard Terms, the connector checks that it is well formed, and you get the contract text and its fingerprint back. Nobody has signed anything at this point: the result is a proposal.

You ask

Draft a master agreement like the conventional example, but with a 3% admin fee and 60 days' termination notice. Check it, then show me the contract text and its fingerprint.

Claude callsget_examplesimulate_eventsrender_texthash_object

Your fingerprint will differ unless every value matches, including the title. That is the point of it: change one character and the fingerprint changes.

When a draft is wrong

The check names the clause and the value at fault. A draft that makes a “distributor” pay the fee comes back as:

The proposed agreement is invalid: clause 'fee': 'distributor' is not a role.

Try next

  • Rename the parties to “Northside Buying Group” and “Acme Supply”, drop the audit clause, and check it again.
  • List the standard Terms I can build with, then explain UP:Tiers.

Keep the example’s parties while you draft. A party is identified by a public key, and the one proposing must be a party to the agreement. Renaming a party is fine. Swapping in a made-up key is rejected.

Give an agent limits everyone can check

A Mandate is a signed statement of what an AI agent may do for a party: which actions, which clauses and which values. Because the limit is data, the supplier, the buyer and every system enforce it the same way. Use this before an agent acts, to see whether its action would be valid for everyone.

You ask

In the mandate-cap example, can the agent raise the price factor to 1.05? What about 1.02?

Claude callssimulate_amendment

Try next

  • What exactly is this agent allowed to do, and until when?
  • What happens if the agent proposes a factor of 0.97?

The second one is rejected too: 0.97 is below the minimum of 0.98. A mandate can bound a value from both sides.

Know what is owed

Fees in Universal Paper are computed from what was reported. Add a month’s sales and the connector returns the fee and its due date under the agreement’s own rate, rounding and payment period. Nothing is recorded: this is a what-if on a copy.

Check invoices

Give Claude the prices on an invoice or a quote. The connector compares each one with the contract price in the tier that applies to that member and tells you which lines are off and by how much.

You ask

In the what-if example, Hypothetical Community Hospital was invoiced 9.40 for GTIN 00000000000017, 22.10 for 00000000000024 and 3.15 for 00000000000031. Which lines match its contract price?

Claude callssimulate_price_conformity

Try next

  • What would those three items cost in tier A?
  • Is Hypothetical Community Hospital an eligible member right now, and since when?

Test a change before anyone signs

Ask what would happen before you commit to it. For a termination, the connector says whether the party may terminate, under which clause, when it would take effect and what is still owed. For an amendment by an agent, see agent limits above.

You ask

In the what-if example, can the aggregator terminate the master agreement now? When would it take effect, and what is still owed?

Claude callssimulate_termination

Try next

  • What if the supplier gives notice instead?
  • List each duty that would still be owed, with its due date.

Start from the contract you have

You do not have to renegotiate anything. An overlay describes a contract you already signed on paper, identified by the hash of its document, and adds just enough structure to compute reports and fees. The paper stays in charge: if the two disagree, the signed contract wins.

You ask

Load the overlay example. What does it say about the original signed contract, and what is owed under it?

Claude callsrender_textderive_state

Try next

  • Adapt the overlay example: change the contract title to “My Supply Agreement” and the admin fee to 2.5%, then check it.

The connector never reads your document. You give it the document’s hash, which you compute yourself from the signed file. Claude can read contract text you paste and model its terms, and the connector then checks that model. The model is Claude’s reading of your contract, so review it.

Limits

  • Group purchasing only, today. The 16 Terms cover agreements between a buying group, its suppliers and its members. It will not model an NDA or an employment contract.
  • It does not read documents. No PDFs and no Word files. It works on agreements written in Universal Paper.
  • It cannot act. It does not sign, send, accept or pay. Every result marked hypothetical changes nothing.
  • It has no opinion on your numbers. It checks structure, signatures and rules. A fee of 30% is as valid to it as a fee of 3%.
  • It is a draft. The language is at version UP/0.1-draft, before 1.0, and the Terms have not been reviewed by counsel.
  • It is not legal advice. The tools report what an agreement written in this language says.

Troubleshooting

Claude answers without using the connector

Check that its toggle is on for this chat: select + in the message box and look under Connectors. Then say what you want it used for, for example “Use Universal Paper to check this.”

The connector will not connect

Check that the address ends in /mcp. Leave authentication empty. Then open mcp.universalpaper.org in a browser: if it shows the server name and version, the server is up and the problem is on the client side.

A result says “rejected”. Is that an error?

No. A rejection is an answer. The tools report what the language decides, and a rejection names the rule that was broken, such as A9 when an agent goes beyond its mandate. The axioms explain each rule.

A tool reports that the input could not be processed

The message says what was wrong, for example an unknown example name with the list of valid ones. Ask Claude to fix the input and try again. If you pasted a bundle, check that it is complete JSON.

Claude invented a party or a key and the draft was rejected

Ask it to keep the parties from the example and change only their names. The one proposing an agreement must be one of its parties.

I am working with confidential terms

Run the server on your own machine with uvx universal-paper-mcp, or seal the private values. The confidential example shows what a sealed agreement looks like.

The tools Claude lists look out of date

Open your connectors, select Universal Paper and reconnect it. Claude then reads the tool list again.
