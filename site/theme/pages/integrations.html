What a shared set of fingerprints can tell you.

Variance maps, parameter ranges, historical deltas and a predictive redline, all recomputed in your browser from hypothetical example bundles. No network calls.

Any channel that lets the receiver recompute the fingerprint works equally well.

These pages describe a few well-known ones; none has special status. Start with the specification instead if you are new to Universal Paper.

For agents: integrations/index.json lists each integration’s docs, helper functions, claim shapes (JSON Schema), examples and the MCP tools to evaluate with. Each page is also available as plain Markdown.
