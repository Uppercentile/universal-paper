How it works

Write it once. Check it anywhere.

No platform to migrate to. Each system reads the same signed agreement and reaches the same answer with an engine of its own.

01

Write in shared Terms

Clauses come from a library of standard Terms with typed parameters, so every system reads them the same way.

02

Fingerprint and sign

The agreement is put in one canonical form and hashed. Signatures cover exactly that fingerprint.

03

Every system verifies

Each copy is re-hashed where it lives. If anyone edits their copy, it stops matching.
