Note 001 says that two parties holding the same bytes get the same answer and can show it. This experiment tests the part of that claim that can be tested today: the fingerprints.

The claim

{{CLAIM}}

If this holds, a party does not have to trust whoever computed an answer. It computes the fingerprint itself and compares. The claim comes from Note 001, Agreements as query surfaces.

What was run

{{METHOD}}

Everything used is public. The bundle is the generative example in the repository, with hypothetical parties. The manifest and the three traces are published as files in Reusable 003.

Check it here
