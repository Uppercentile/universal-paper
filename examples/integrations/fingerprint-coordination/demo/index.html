What a shared set of fingerprints can tell you.

Every number below is derived from the hypothetical example bundles already published in the Universal Paper repository, and every input is named by its fingerprint, so anyone can recompute this page's profile byte for byte. Seeds are candidates produced by a fixed rule and run through the Universal Paper engine. They are not recommendations, benchmarks or market data.
