# Universal Paper

A first-order language for agreements between group purchasing organizations, suppliers, and members.

Universal Paper is a vocabulary, a grammar, and a set of validity rules. It is not an application. Anyone can verify an agreement written in it, offline, from the specification alone.

**Status:** `UP/0.1-draft`. The specification is a working draft. The reference interpreter, schemas, examples, and Explorer are not yet built.
